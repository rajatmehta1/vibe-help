Quick Start Guide

Get ForgeLine running locally in minutes. This guide covers Docker setup (recommended), local development setup, creating your first project, and installing the VS Code extension.

Prerequisites

Required

  • Docker 20.10+ and Docker Compose v2+
  • Git for cloning the repository

For Local Development (without Docker)

  • Python 3.11+
  • Node.js 18+ and npm 9+
  • PostgreSQL 15+ with the pgvector extension
  • Neo4j 5+
  • Redis 7+

API Keys

  • Anthropic API Key — for Claude-powered code analysis
  • OpenAI API Key (optional) — for additional AI analysis capabilities

1. Clone the Repository

git clone https://github.com/your-org/forgeline.git
cd forgeline

2. Docker Setup (Recommended)

Docker Compose is the fastest way to get all services running.

Step 1: Create the environment file

Copy the example environment file and fill in your values:

cp .env.example .env

Edit .env with your configuration:

# Database
DATABASE_URL=postgresql+asyncpg://forgeline:forgeline@postgres:5432/forgeline

# Neo4j
NEO4J_URI=bolt://neo4j:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your-neo4j-password

# Redis
REDIS_URL=redis://redis:6379/0

# Auth
JWT_SECRET=your-secret-key-change-in-production

# AI Providers
ANTHROPIC_API_KEY=sk-ant-your-key-here
OPENAI_API_KEY=sk-your-key-here

Step 2: Start all services

docker compose up -d

This starts PostgreSQL (with pgvector), Neo4j, Redis, the backend API, and the dashboard.

Step 3: Run database migrations

docker compose exec backend alembic upgrade head

Step 4: Seed built-in policies

docker compose exec backend python -m app.scripts.seed_policies

Step 5: Verify everything is running

Service URL Expected Result
Backend API http://localhost:8000/docs Swagger UI
Dashboard http://localhost:3000 Login page
Neo4j Browser http://localhost:7474 Neo4j web interface

3. Local Development Setup

For active development, you may want to run services individually. See Deploy Without Docker for full manual installation instructions.

Backend

# Create and activate virtual environment
cd backend
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run migrations
alembic upgrade head

# Seed policies
python -m app.scripts.seed_policies

# Start the development server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Dashboard

# Install dependencies
cd dashboard
npm install

# Start the development server (Vite)
npm run dev

The dashboard dev server runs on http://localhost:5173 with hot module replacement enabled.

VS Code Extension (Development)

# Install dependencies
cd vscode-extension
npm install

# Compile
npm run compile

# Press F5 in VS Code to launch the Extension Development Host

4. Create Your First Project

Step 1: Register an account

curl -X POST http://localhost:8000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "you@example.com",
    "password": "your-password",
    "full_name": "Your Name",
    "org_name": "My Organization"
  }'

Step 2: Log in to get a JWT token

curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "you@example.com",
    "password": "your-password"
  }'

Save the access_token from the response.

Step 3: Create a project

curl -X POST http://localhost:8000/api/v1/projects \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{
    "name": "My First Project",
    "description": "Testing ForgeLine code governance"
  }'

Step 4: Enable policies on the project

curl -X POST http://localhost:8000/api/v1/projects/PROJECT_ID/policies \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{
    "policy_id": "POLICY_UUID",
    "enabled": true,
    "severity": "warning"
  }'

Step 5: Run your first scan

curl -X POST http://localhost:8000/api/v1/scans \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{
    "project_id": "PROJECT_ID",
    "file_name": "example.py",
    "language": "python",
    "code": "import os\npassword = \"hardcoded_secret\"\nos.system(f\"rm -rf {user_input}\")"
  }'

The response will include findings from enabled policies, such as OWASP Security flagging the hardcoded password and command injection.

5. Install the VS Code Extension

From VSIX (local install)

# Build the extension package
cd vscode-extension
npm run package

# Install in VS Code
code --install-extension forgeline-0.1.0.vsix

Configure the extension

Open VS Code settings (Ctrl+, / Cmd+,) and search for "ForgeLine":

Setting Value Description
forgeline.serverUrl http://localhost:8000 Backend API URL
forgeline.apiKey Your JWT token Authentication token
forgeline.projectId Your project UUID Target project for scans
forgeline.autoScan true Enable automatic scanning
forgeline.scanOnSave true Scan when files are saved
forgeline.severityThreshold warning Minimum severity to show

Or add to your settings.json:

{
  "forgeline.serverUrl": "http://localhost:8000",
  "forgeline.apiKey": "your-jwt-token",
  "forgeline.projectId": "your-project-id",
  "forgeline.autoScan": true,
  "forgeline.scanOnSave": true,
  "forgeline.severityThreshold": "warning"
}

Verify the extension

  1. Open a code file in your project
  2. Save the file (if scan-on-save is enabled) or run ForgeLine: Scan Current File from the command palette (Ctrl+Shift+P)
  3. Check the Problems panel for findings
