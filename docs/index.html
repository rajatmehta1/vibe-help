ForgeLine Documentation

Welcome to the official documentation for ForgeLine — an AI-generated code governance platform that helps teams enforce coding standards, security policies, and architectural guidelines across their projects.

What is ForgeLine?

ForgeLine automatically scans AI-generated and human-written code against configurable policy templates. It catches security vulnerabilities, naming convention violations, architectural drift, and more — before code reaches production.

The platform ships as a monorepo containing a FastAPI/Python backend, a React/TypeScript dashboard, and a VS Code extension, backed by PostgreSQL (with pgvector), Neo4j, and Redis.
