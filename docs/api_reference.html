API Reference

Complete reference for the ForgeLine REST API. All endpoints are prefixed with /api/v1. The backend runs on port 8000 by default. Interactive Swagger documentation is available at /docs.

Authentication

Most endpoints require a JWT bearer token in the Authorization header:

Authorization: Bearer <your-jwt-token>

Obtain a token by calling the login endpoint. Tokens are signed with the JWT_SECRET environment variable.

Response Envelope

Successful responses return the resource directly as JSON. Errors use the following format:

{
  "detail": "Description of what went wrong"
}

Authentication

POST /api/v1/auth/register

Register a new user account and organization.

Auth required: No

Request Body

{
  "email": "user@example.com",
  "password": "securepassword",
  "full_name": "Jane Doe",
  "org_name": "Acme Corp"
}

Response 201 Created

{
  "id": "uuid",
  "email": "user@example.com",
  "full_name": "Jane Doe",
  "org_id": "uuid",
  "created_at": "2026-01-15T10:00:00Z"
}

Error Responses

StatusDetail
400Validation error (missing fields, weak password)
409Email already registered

POST /api/v1/auth/login
