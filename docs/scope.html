Project Scope

This document defines the boundaries, purpose, and capabilities of the ForgeLine platform.

What ForgeLine Does

ForgeLine is an AI-generated code governance platform that automatically analyzes source code against configurable policy templates. It identifies security vulnerabilities, naming convention violations, architectural drift, error handling gaps, dependency risks, performance issues, and documentation shortcomings.

The platform provides a centralized dashboard for teams to manage projects, configure policies, review scan results, and track compliance trends over time. A companion VS Code extension enables real-time scanning directly within the developer's editor.

Target Audience

  • Engineering teams that use AI code generation tools (Copilot, Claude, ChatGPT) and need governance over the generated output
  • Tech leads and architects who want to enforce coding standards and architectural patterns across projects
  • Security teams that need to ensure OWASP compliance and catch vulnerabilities early
  • Organizations adopting AI-assisted development that require audit trails and policy enforcement

Key Capabilities

Policy Management

ForgeLine ships with 7 built-in policy templates:

Policy Description
OWASP Security Detects common security vulnerabilities aligned with the OWASP Top 10
Naming Conventions Enforces consistent naming patterns for variables, functions, classes, and files
Architecture Validates adherence to defined architectural layers and dependency directions
Error Handling Checks for proper error handling, logging, and graceful degradation
Dependencies Audits third-party dependencies for known vulnerabilities and license issues
Performance Identifies common performance anti-patterns and optimization opportunities
Documentation Ensures code includes adequate docstrings, comments, and API documentation

Policies can be enabled or disabled per project and configured with custom severity thresholds.

Code Scanning

  • Submit code snippets or full files for analysis via API or VS Code extension
  • AI-powered analysis using Anthropic (Claude) and OpenAI models
  • Results include severity levels, line-specific findings, and remediation suggestions
  • Scan history is preserved for audit and trend analysis

Knowledge Graph

  • Neo4j-backed graph of relationships between projects, policies, scans, and violations
  • Enables cross-project pattern detection and organizational compliance views
  • Supports vector similarity search via pgvector for finding related code issues

User & Organization Management

  • JWT-based authentication
  • User and organization model with role-based access
  • Per-organization project and policy management

Developer Experience

  • VS Code extension with scan-on-save capability
  • React-based dashboard with project overview, scan results, and policy configuration
  • RESTful API for integration with existing toolchains

In Scope

  • Backend API server (FastAPI/Python) with all CRUD and scanning endpoints
  • React/TypeScript/Tailwind dashboard for project and policy management
  • VS Code extension for in-editor scanning
  • PostgreSQL with pgvector for relational data and vector embeddings
  • Neo4j for knowledge graph storage and traversal
  • Redis for caching and background task queuing
  • Docker Compose setup for local development and deployment
  • JWT-based authentication and authorization
  • 7 built-in policy templates with configurable severity levels
  • AI-powered code analysis via Anthropic and OpenAI APIs
  • Scan history, result storage, and basic reporting

Out of Scope (Phase 1)

The following items are not included in the current release but are planned for Phase 2:

  • CI/CD pipeline integration (GitHub Actions, GitLab CI, Jenkins)
  • GitHub Pull Request bot for automated review comments
  • Custom LLM rule authoring by end users
  • Advanced team management (roles, permissions, SSO)
  • Webhook support for external notifications
  • VS Code Marketplace publishing
  • Multi-language support beyond the initially supported languages
  • Self-hosted LLM inference (currently depends on cloud APIs)
  • Real-time collaborative editing of policies
  • Mobile or tablet dashboard views
