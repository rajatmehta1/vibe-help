# ForgeLine

**AI-Generated Code Governance Platform**

ForgeLine is a comprehensive platform for governing AI-generated code in software projects. It detects when code is generated by AI tools (Copilot, ChatGPT, Claude, etc.), analyzes it against your project's coding standards and conventions, and provides real-time feedback through VS Code, a web dashboard, and CI/CD integrations.

```
+---------------------+     +------------------------+     +------------------+
|   VS Code Extension | --> |    Backend API (FastAPI)| --> |   PostgreSQL     |
|   - AI Detection    |     |    - Auth (JWT)         |     |   + pgvector     |
|   - Real-time Scan  |     |    - Policy Engine      |     +------------------+
|   - Diagnostics     |     |    - Code Indexer       |
|   - Quick Fixes     |     |    - Convention Learner |     +------------------+
+---------------------+     +------------------------+ --> |   Neo4j          |
                                       |                    |   Knowledge Graph|
+---------------------+               |                    +------------------+
|   React Dashboard   | <-------------+
|   - Policy Mgmt     |               |                    +------------------+
|   - Scan History    |               +-------------------> |   Redis          |
|   - Intelligence    |               |                    |   Cache + Queue  |
|   - Settings        |     +---------+----------+        +------------------+
+---------------------+     |  Celery Workers     |
                             |  - Background Index |
                             |  - Convention Learn |
                             +--------------------+
```

## Features

- **AI Code Detection** - Automatically detects AI-generated code insertions based on typing patterns, code structure, and heuristics
- **Real-time Policy Enforcement** - Scans code against security, naming, architecture, and error handling policies as you write
- **Codebase Intelligence** - Learns your project's conventions, patterns, and architecture through code indexing and Neo4j knowledge graph
- **7 Built-in Policy Templates** - OWASP Security, Naming Conventions, Layered Architecture, Error Handling, Dependency Safety, Performance, Documentation
- **Custom Policies** - Create custom policies via the dashboard or import from YAML
- **VS Code Integration** - Inline diagnostics, quick fixes, tree view sidebar, summary panel
- **Web Dashboard** - Full management UI with charts, scan history, and codebase intelligence visualization

## Getting Started

### Prerequisites

- **Docker** and **Docker Compose** (for databases)
- **Node.js** 18+ (for dashboard and VS Code extension)
- **Python** 3.12+ (for backend)

### Quick Start

1. **Start infrastructure services:**
   ```bash
   docker-compose up -d postgres neo4j redis
   ```

2. **Start the backend:**
   ```bash
   cd backend
   pip install -r requirements.txt
   alembic upgrade head
   uvicorn app.main:app --reload --port 8000
   ```

3. **Start the Celery worker** (separate terminal):
   ```bash
   cd backend
   celery -A app.workers.celery_app worker --loglevel=info
   ```

4. **Start the dashboard:**
   ```bash
   cd dashboard
   npm install
   npm run dev
   ```

5. **Install the VS Code extension:**
   ```bash
   cd vscode-extension
   npm install && npm run build
   npx vsce package
   code --install-extension forgeline-0.0.1.vsix
   ```

6. **Configure:**
   - Open the dashboard at `http://localhost:5173`
   - Register an account
   - Create a project (set the root path to your codebase)
   - Copy the JWT token and project ID to VS Code settings:
     - `forgeline.apiKey`: Your JWT token
     - `forgeline.projectId`: Your project UUID

### Full Docker Deployment

```bash
docker-compose up -d
```

This starts all services:
- Backend API: `http://localhost:8000`
- Dashboard: `http://localhost:3000`
- Neo4j Browser: `http://localhost:7474`
- PostgreSQL: `localhost:5432`
- Redis: `localhost:6379`

## VS Code Extension

| Command | Description |
|---------|-------------|
| `ForgeLine: Scan Current File` | Analyze the active file against policies |
| `ForgeLine: Scan Workspace` | Scan all open files |
| `ForgeLine: Scan Selection` | Analyze selected code |
| `ForgeLine: Index Workspace` | Trigger full codebase indexing |
| `ForgeLine: Inject Context` | Copy conventions to clipboard for AI tools |
| `ForgeLine: Mark as AI Generated` | Mark selected code as AI-generated |
| `ForgeLine: Show Summary` | Open the violations summary panel |
| `ForgeLine: Refresh Tree` | Refresh the violations tree view |

### How It Works

1. **Change Tracking** - Monitors text insertions for rapid, large, or pasted code
2. **AI Detection** - Scores insertions using heuristics (typing speed, code structure, formatting consistency)
3. **Analysis** - Sends detected AI code to the backend `/analyze` endpoint
4. **Diagnostics** - Shows violations as VS Code Problems with inline squiggly lines
5. **Quick Fixes** - Offers code actions to fix violations or suppress warnings

## Policy Customization

### Built-in Templates

Activate templates from the dashboard's Policies page:
- **OWASP Security Basics** - SQL injection, XSS, hardcoded secrets
- **Naming Conventions** - snake_case, PascalCase, descriptive names
- **Layered Architecture** - Layer boundaries, dependency direction
- **Error Handling** - No bare except, consistent error types
- **Dependency Safety** - Deprecated packages, version pinning
- **Performance Basics** - N+1 queries, unnecessary recomputation
- **Documentation Required** - Docstrings, module docs

### Custom Policies via YAML

```yaml
name: No Console Log
description: Forbid console.log in production code
category: security
severity_default: warning
is_active: true
configuration:
  pattern: "console\\.log"
  message: Remove console.log before committing
```

Import via `POST /api/v1/projects/{id}/policies/import` with YAML body.

## API Documentation

### Auth
- `POST /api/v1/auth/register` - Register new user
- `POST /api/v1/auth/login` - Login, returns JWT
- `GET /api/v1/auth/me` - Get current user

### Projects
- `POST /api/v1/projects/` - Create project
- `GET /api/v1/projects/` - List projects
- `GET /api/v1/projects/{id}` - Get project detail
- `PUT /api/v1/projects/{id}` - Update project
- `DELETE /api/v1/projects/{id}` - Delete project

### Policies
- `GET /api/v1/policies/builtin` - List builtin templates
- `POST /api/v1/projects/{id}/policies` - Create policy
- `GET /api/v1/projects/{id}/policies` - List policies
- `GET /api/v1/projects/{id}/policies/{pid}` - Get policy detail
- `PUT /api/v1/projects/{id}/policies/{pid}` - Update policy
- `DELETE /api/v1/projects/{id}/policies/{pid}` - Delete policy
- `POST /api/v1/projects/{id}/policies/import` - Import YAML policy

### Analysis
- `POST /api/v1/projects/{id}/analyze` - Analyze code against policies

### Indexing
- `POST /api/v1/projects/{id}/index` - Trigger full index
- `POST /api/v1/projects/{id}/index/incremental` - Trigger incremental index
- `GET /api/v1/projects/{id}/index/status` - Get indexing status
- `GET /api/v1/projects/{id}/knowledge/stats` - Knowledge graph stats

### Knowledge
- `GET /api/v1/projects/{id}/patterns` - List detected patterns
- `GET /api/v1/projects/{id}/patterns/{pid}/evidence` - Get pattern evidence
- `GET /api/v1/projects/{id}/conventions` - List conventions
- `GET /api/v1/projects/{id}/architecture` - Get architecture overview
- `POST /api/v1/projects/{id}/similar` - Find similar code
- `POST /api/v1/projects/{id}/learn` - Trigger convention learning

### Audit
- `GET /api/v1/projects/{id}/audit` - List audit log entries

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Backend won't start | Check `DATABASE_URL` and ensure PostgreSQL is running |
| Neo4j connection failed | Verify Neo4j is running on port 7687, check credentials |
| Extension shows "Disconnected" | Verify backend is running, check `forgeline.serverUrl` setting |
| No violations detected | Ensure policies are activated for your project |
| Indexing stuck | Check Celery worker is running and Redis is accessible |
| Dashboard login fails | Verify backend is running at the URL configured in `dashboard/src/services/apiClient.ts` |
