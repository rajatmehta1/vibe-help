# ForgeLine for VS Code

Govern AI-generated code in real-time. ForgeLine detects when code is generated by AI tools, analyzes it against your project's policies and conventions, and provides inline feedback right in your editor.

## Features

- **AI Code Detection** - Automatically detects AI-generated code based on typing patterns and insertion heuristics
- **Real-time Analysis** - Scans detected AI code against security, naming, architecture, and error handling policies
- **Inline Diagnostics** - Shows violations as squiggly underlines with detailed messages in the Problems panel
- **Quick Fixes** - Offers one-click fixes and suppression options via Code Actions
- **Tree View Sidebar** - Hierarchical view of all violations grouped by severity
- **Summary Panel** - Rich webview showing violation details for the current file
- **Context Injection** - Copies your project's conventions to clipboard for use with AI coding tools
- **Scan on Save** - Automatically scans files when saved

## Installation

### From VSIX

```bash
cd vscode-extension
npm install && npm run build
npx vsce package
code --install-extension forgeline-0.0.1.vsix
```

### From Source (Development)

```bash
cd vscode-extension
npm install
# Press F5 in VS Code to launch Extension Development Host
```

## Configuration

Open VS Code Settings and search for "ForgeLine":

| Setting | Default | Description |
|---------|---------|-------------|
| `forgeline.serverUrl` | `http://localhost:8000` | ForgeLine backend API URL |
| `forgeline.apiKey` | _(empty)_ | JWT token from the dashboard |
| `forgeline.projectId` | _(empty)_ | Project UUID to analyze against |
| `forgeline.autoScan` | `true` | Automatically scan detected AI code |
| `forgeline.scanOnSave` | `true` | Scan files when saved |
| `forgeline.severityThreshold` | `warning` | Minimum severity level to display |

## Commands

Access via Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`):

| Command | Description |
|---------|-------------|
| `ForgeLine: Scan Current File` | Analyze the active file against all active policies |
| `ForgeLine: Scan Workspace` | Scan all open files in the workspace |
| `ForgeLine: Scan Selection` | Analyze only the selected code |
| `ForgeLine: Index Workspace` | Trigger full codebase indexing on the server |
| `ForgeLine: Inject Context` | Copy project conventions to clipboard |
| `ForgeLine: Mark as AI Generated` | Mark selected code with AI-generated markers |
| `ForgeLine: Show Summary` | Open the violations summary webview panel |
| `ForgeLine: Refresh Tree` | Refresh the violations tree view |

## How It Works

```
  Text Change
      |
      v
  ChangeTracker -----> AICodeDetector
  (monitors edits)     (scores insertion)
      |                      |
      |  confidence > 0.6    |
      v                      v
  ApiClient.analyze() <--- Policy Engine
      |                    (server-side)
      v
  DiagnosticProvider
  (inline squiggles)
      |
      +---> QuickFixProvider (code actions)
      +---> TreeView (sidebar)
      +---> SummaryPanel (webview)
      +---> StatusBar (connection status)
```

1. **ChangeTracker** monitors text document changes, detecting rapid/large insertions or paste events
2. **AICodeDetector** scores each insertion for AI-generation likelihood using heuristics
3. If confidence exceeds threshold, the code is sent to the backend's `/analyze` endpoint
4. The backend evaluates code against all active policies for the project
5. Violations are displayed as VS Code diagnostics with severity-based squiggly lines
6. Quick fix code actions offer resolution suggestions
7. Status bar shows connection state and violation count

## Status Bar

The status bar indicator shows:
- **$(check) Connected** - Backend is reachable, no violations
- **$(warning) N** - N violations found in current workspace
- **$(close) Disconnected** - Cannot reach backend (click to retry)
- **$(sync~spin) Indexing** - Indexing or scanning in progress

## Context Menu

Right-click in the editor for:
- **ForgeLine: Scan Selection** - Analyze highlighted code
- **ForgeLine: Mark as AI Generated** - Add AI-generated markers

## Requirements

- ForgeLine backend running (default: `http://localhost:8000`)
